# Product

## Register

product

## Users

Agent Tray is a personal macOS utility for developers who use multiple local AI coding agents and need a quick view of quota, recent activity, and provider health without opening each agent.

## Product Purpose

Provide a compact, trustworthy menu-bar view of Grok and every discovered Codex profile or provider. Success means the user can identify current usage, reset timing, recent activity, and stale or unavailable data in a few seconds.

## Brand Personality

Calm, precise, compact. Copy is direct and operational. The interface should feel native to macOS and visually quiet during repeated daily use.

## Anti-references

Avoid a generic web dashboard inside a popover, nested cards, decorative glass effects, terminal cosplay, excessive gradients, and provider branding that overwhelms the data.

## Design Principles

- Make freshness and data provenance obvious.
- Prefer one readable hierarchy over a wall of metrics.
- Treat unavailable data as a normal, useful state.
- Preserve familiar macOS behaviors and controls.
- Read usage metadata without collecting conversation content or secrets.

## Accessibility & Inclusion

Support VoiceOver, keyboard navigation, increased contrast, reduced motion, color-independent status indicators, and readable layouts at macOS accessibility text sizes.
