# Product

## Register

product

## Users

Agent Tray is a personal macOS utility for developers who use multiple local AI coding agents and need a persistent glance at quota and reset timing without opening each agent.

## Product Purpose

Provide an always-visible edge notch for Cursor, Grok, and every discovered Codex profile or provider. Success means the user can read current usage and reset timing in a glance, and inspect a profile’s quota windows on hover.

## Brand Personality

Calm, precise, compact. Copy is direct and operational. The notch should feel like hardware: dark, quiet, and unobtrusive during long work sessions.

## Anti-references

Avoid a generic web dashboard, nested cards, decorative glass effects, terminal cosplay, excessive gradients, and provider branding that overwhelms the data.

## Design Principles

- Keep the notch always present; details appear only on hover.
- Prefer one number per agent on the notch, full quota windows in the tooltip.
- Treat unavailable data as a normal, useful state.
- Read usage metadata without collecting conversation content or secrets.

## Accessibility & Inclusion

Support VoiceOver, increased contrast, reduced motion, color-independent status indicators, and readable type at macOS accessibility text sizes.
